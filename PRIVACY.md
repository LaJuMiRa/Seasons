# Privacy

Seasons runs entirely on your Mac.

- **No network access.** The app contains no networking code, no analytics, no telemetry and no update checks.
- **No data collection.** Nothing is sent anywhere.
- **What it reads, only in memory:** the position and size of on-screen windows (to let snow lie on them), the mouse pointer position (to sweep particles), and the Dock preferences (position, auto-hide, icon size, number of items). It never reads window titles or contents.
- **What it stores:** your menu choices in `~/Library/Preferences/com.laurenzrauscher.Seasons.plist`.
- **Permissions:** none required. If macOS restricts window information, Seasons offers to open the Screen Recording settings. Granting it is optional and only enables piles on windows.
